## 🚀 Run Locally

### Prerequisites

- Node.js
- npm

### Installation

```bash
npm install
```

### Environment

Create `.env.local` and add the required Gemini API key used by the project.

```env
GEMINI_API_KEY=your_api_key_here
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
